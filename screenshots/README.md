# Screenshots

Place your project screenshots in this folder and name them exactly as below.
The README.md references these filenames.

| Filename              | What to capture                                      |
|-----------------------|------------------------------------------------------|
| architecture.png      | Architecture diagram (draw.io / hand-drawn photo)    |
| website-form.png      | Website open in browser — empty form                 |
| form-filled.png       | Form filled with employee data before submit         |
| submit-success.png    | Green success toast after adding employee            |
| employee-table.png    | Table showing list of all employees                  |
| dynamodb-table.png    | DynamoDB console showing saved items                 |
| lambda-console.png    | Lambda function code in AWS console                  |
| apigateway-routes.png | API Gateway showing GET and POST routes              |
| s3-bucket.png         | S3 bucket with uploaded website files                |
| cloudwatch-logs.png   | CloudWatch logs showing Lambda execution             |

## How to take screenshots on Windows
- Full screen:        Win + PrtScn  (saved to Pictures/Screenshots)
- Selected area:      Win + Shift + S  (snipping tool)
- Active window:      Alt + PrtScn

## Tip
Crop screenshots to show only the relevant part.
Remove any personal account IDs or sensitive info before uploading.
